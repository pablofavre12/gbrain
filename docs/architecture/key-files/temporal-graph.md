# Temporal graph

- `src/core/link-validity.ts` + `src/core/link-relationships.ts` + `src/core/link-temporal-evidence.ts` + `src/core/link-temporal-apply.ts` + `src/core/ops/edge-temporal.ts` — temporal typed edges ([guide](../../guides/temporal-edges.md)). Relation semantics (state / event / reference), `buildRelationshipState` (order-invariant stints from `links` assertions with `assertion_tense` plus dated `link_transitions`; dated beats undated, same-page present beats past), `closeContradiction` (pure date arithmetic, relationship-specific starts only), and `relationshipFilterSql` / `annotateTemporalRow` / `edgeMatchesTemporal` (one liveness rule: a relationship with no `link_relationships` row reads live). `src/core/link-temporal-read-sql.ts` derives scoped state and timestamps from authorized evidence before aggregation; ACL/source values remain bound. Unrestricted local reads retain the projection. `refreshRelationships` recomputes stored state (`all`, `world` excludes private-origin evidence) inside the writer's transaction; `replaceDerivedLinks` calls `applyTemporalEvidence`, and the engine link writers refresh touched temporal keys; the extract phase sweeps lagging or orphaned state. Graph ops read live relationships by default; default reads keep the established row shape, history reads (`status`, `as_of`, `during`) return `status`/`stints`/`recorded_at`/`retired_at`; hidden rows emit `former_relationships_hidden` + `gbrain.temporal` meta. `graph.edge_validity off` is a read policy only. `src/core/link-semantics-pack.ts` installs pack-declared `link_types[].temporal` semantics (union of the active and per-source packs, `state` wins) over the built-in table; `replaceDerivedLinks`, `add_link`/`remove_link` and the extract sweep prime it before deriving or refreshing state (lint rule `link_types_temporal`; `test/link-semantics-pack.test.ts`). `src/core/link-relationship-notes.ts` renders the shared relationship note (`now: … ; ended: … ; summary may be stale`) with one batched policy-scoped read for entity cards, `context_pack`, ambient turn-context synopses and public-only compiled context entries. Pinned by `test/link-validity.test.ts`, `test/link-temporal-evidence.test.ts`, `test/link-relationships.test.ts` (+ Postgres twin), `test/link-temporal-put-page.test.ts`, `test/link-temporal-reads.test.ts`.

- `src/core/cycle/edge-contradictions.ts` + `src/commands/edge-proposals.ts` — the `edge_contradictions` dream phase and `gbrain edge-proposals`. Candidates are subjects with ≥2 live same-type state relationships whose pair evidence hash has no proposal; one judge call per subject returns only conflict flags; `closeContradiction` picks the ending relationship and date (undated → `undated_unresolved`). Modes propose / apply / off; without an explicit mode, certified models in `CERTIFIED_APPLY_MODELS` default to apply and other models to propose; applying appends a `gbrain-dream (inferred)` "Ended <type> [[target]]" timeline line through the coordinated `add_timeline_entry` path and re-derives the page; a hand-deleted line becomes `reverted_by_user`. `list` reads `--status` and `--limit` as `--flag value` or `--flag=value`; `--limit` is a positive integer (`intFlagValue`, a bad or missing value is `invalid_params` before any query) capped at 1000 (`test/edge-proposals-list-flags.test.ts`). Budget through the cycle `BudgetMeter`. The CLI's `rows()` normalizes proposal ids at the row boundary (Postgres returns `bigint` as BigInt: a safe integer becomes a number, anything larger an exact string) and `--json` output also passes `bigintToStringReplacer`, so `list/show --json` never crash on Postgres (#6193). Pinned by `test/cycle-edge-contradictions.test.ts`, the managed phase matrix, `test/edge-proposals-json-bigint.test.ts` and `test/e2e/edge-proposals-json-postgres.test.ts`. `edge-proposals <sub> --help` prints usage before any engine read (router help, `src/cli/subcommands.ts`). #6311: a judge failure writes an `error` row whose detail is `attempt N/3; <class>: <message>` (provider keys, connection info and labeled credentials redacted, message ≤ 200 chars); skip-known treats it as known for 24 h (`updated_at`), then the pair is judged again and `recordProposal` renews an `error` row after backoff or a stale/obsolete open proof after fresh evidence capture; rejected/reverted decisions remain final for that evidence; after `JUDGE_MAX_ATTEMPTS` (3) the detail reads `held after 3 attempts; …` and the pair is skipped until `gbrain edge-proposals retry <id> | --all-held` deletes the row (or the evidence hash changes). No migration. Pinned by `test/cycle-edge-contradictions.test.ts`.
- `src/core/link-single-value.ts` — declared single-value relations ([guide](../../guides/temporal-edges.md#declared-single-value-relations)). A pack's `cardinality: one_per_from` on a state relation, built in or declared `temporal: state` (manifest-v1 `LinkTypeSchema`; lint rule `link_types_cardinality` rejects it elsewhere) makes `edge_contradictions` close that type's competing live relationships without a model: `planSingleValueClosures` orders members by latest dated start and applies `closeContradiction` to each consecutive pair (undated and same-date members stay open as proposals). `declaredSingleValueTypes` reads the source's resolved pack; `previewSingleValue` backs the read-only `gbrain schema cardinality-preview`. `dream.single_value.mode` propose (default) / apply / off. After each applied closure the cycle captures current evidence again and recomputes the deterministic plan; an ACL or evidence change stops publication. Pinned by `test/link-single-value.test.ts` and the shared edge-closure publication-guard scenarios.

- Reader-scoped metadata: `wanted_pages` filters origins before aggregation and eligible existing targets before suggestion matching; `list_link_sources` filters both endpoints and independent origins before counting. `entity_identity_list` passes the reader subjects to seed/member filtering. Shared graph metadata scenarios exercise positive grants, denied origins/endpoints and revocation on both engines.

- `src/core/persistence/timeline-publication-guard.ts` — captures immutable public evidence and page/source identity, then validates it under publication locks in the canonical page transaction. Derived pages without verifiable complete lineage are refused. `src/core/eval-contradictions/timeline-writer.ts` revalidates each original finding immediately before writing; cached reports require current chunk/take provenance and matching effective dates and date sources on both owning pages. The guard pins both temporal fields to refuse corrections made after capture; regenerate stale reports before publishing. The guard is internal and cannot be replayed as an ordinary timeline write. See the [publication boundary](../../guides/temporal-edges.md#reader-permissions).
